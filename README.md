# Anorbank — «Мониторинг расходов»

Премиальный продуктовый ролик на [Remotion](https://remotion.dev): 77 секунд, 1920×1080, 30 fps.

Идея: по структуре расходов видно, какой ты человек. Типографика — не подпись
к телефону, а главный герой: слово «РАСХОДЫ» физически превращается в круговую
диаграмму, камера пролетает сквозь неё в продукт, и дальше каждое слово связано
с живым значением на графике.

## Быстрый старт

```bash
npm install
npm start                 # Remotion Studio на http://localhost:3000
npm run render            # финальный H.264 в out/
npm run render:preview    # быстрый черновик (0.5x, высокий CRF)
npm run typecheck
```

В окружениях без своего Chrome добавьте к рендеру
`--browser-executable=<путь к chrome/headless_shell> --gl=swangle`.

## Архитектура

Фильм — **один непрерывный кадр**. Сцен как контейнеров не существует: нет ни
одного `<Sequence>`, все элементы читают одни и те же часы и живут в мировых
координатах, а «главы» — это участки маршрута камеры. Глава не может
«начаться» или «сброситься», потому что начинать нечего: есть только камера,
которая не останавливается, и элементы, чьи окна перекрываются на стыках.


### Как это работает

**Проекция.** У объекта мировые координаты, у камеры — позиция и зум; на экран
попадает их проекция. `parallax` задаёт глубину слоя: 1 — вровень с продуктом,
больше 1 — ближе к объективу (движется и растёт быстрее), меньше — дальше.
Именно это позволяет камере пролетать *сквозь* объект: ближний уходит за край
кадра, а то, что за ним, только приближается.

**Камера смотрит на данные.** В `world.ts` есть окна `LOOK_AT_CHART`, где
камера перестаёт идти по своему пути и наводится на живую позицию диаграммы.
Поэтому «камера следует за растущим сегментом» — буквальная правда, а не
совпадение чисел, скопированных из другой таблицы.

**Разрежённые кейфреймы.** `keyframes.ts` интерполирует каждый канал отдельно
по тем ключам, где он упомянут. Отсюда ловушка: канал, названный на кадре 100 и
затем на 900, будет ползти все 800 кадров между ними. Там, где значение должно
стоять, таблица обязана сказать об этом удерживающим ключом.

## Как править

**Тайминг.** Все моменты — в `src/beats.ts`. Музыкальная сетка (`beatFrame`,
`snapToBeat`) выводится из `MUSIC.bpm` в `src/timeline.ts`.

**Движение камеры.** `src/world.ts`, таблица `CAM`. Читается сверху вниз как
раскадровка.

**Движение телефона.** `src/phonePath.ts`. Не забывайте удерживающие ключи.
Инерция считается в `PhoneObject.tsx` из скорости по пути (сэмпл на 5 кадров
назад): корпус кренится в сторону движения и слегка отстаёт от него.

**Свечение типографики.** У `Word` есть проп `glow` (0–1). Свет тонируется
цветом самой буквы, а не белым, иначе читается как фильтр поверх текста, а не
как свечение текста.

**Счётчики.** `springNumber()` в `motion.ts`. Линейно считающееся число —
самый заметный признак того, что кадр отрендерен, а не снят.

**Музыка.** Положить трек в `public/audio/trendsetter.mp3`, выставить в
`MUSIC`: `enabled: true`, реальные `bpm` и `offsetSec` (секунда первой доли).
После этого сцены пересобираются под бит правкой одной константы.

**Цифры и категории.** `src/data/categories.ts`: `STATES` — четыре состояния
диаграммы (каждое в сумме 100), `CHART_KEYFRAMES` — когда происходит переход.
Диаграмма и список читают одни и те же значения, поэтому расхождений быть не может.

**Бренд.** `src/theme.ts` — цвета и типографика. Точный HEX гранатового
красного меняется в `brand.red`.

**Моушн.** `src/motion.ts` — единственное место, где живут кривые. `easeOutBack`
даёт перелёт (рост сегментов, появление слов), `drift` — органическое покачивание
из трёх синусов, `kick` — импульс на границе сцены, `SPRING` — четыре пресета
пружин. Амплитуда движения камеры настраивается в `src/components/Camera.tsx`:
множители при `drift(...)` и `cutZoom`.

**Логотип.** Заменить тело `src/components/Logo.tsx` на
`<Img src={staticFile('logo/anorbank.svg')} />` — больше нигде логотип не используется.
