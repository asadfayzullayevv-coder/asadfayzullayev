# Anorbank — «Мониторинг расходов»

Премиальный продуктовый ролик на [Remotion](https://remotion.dev): 76 секунд, 1920×1080, 30 fps.

Идея: по структуре расходов видно, какой ты человек. Типографика — не подпись
к телефону, а главный герой: слово «РАСХОДЫ» физически превращается в круговую
диаграмму, камера пролетает сквозь неё в продукт, и дальше каждое слово связано
с живым значением на графике.

## Быстрый старт

```bash
npm install
npm start                 # Remotion Studio на http://localhost:3000
npm run render            # финальный H.264 в out/
npm run render:preview    # быстрый черновик (0.5x, высокий CRF)
npm run typecheck
```

В окружениях без своего Chrome добавьте к рендеру
`--browser-executable=<путь к chrome/headless_shell> --gl=swangle`.

## Как править

**Тайминг.** Всё в `src/timeline.ts`. Сцены заданы в секундах, `beatFrame()` и
`snapToBeat()` считают музыкальную сетку от `MUSIC.bpm`.

**Движение телефона.** `src/staging.ts` — одна таблица кейфреймов на весь фильм.
Каждый канал (x, y, scale, rotY, blur, opacity) тянется от своего последнего
упоминания, поэтому перед каждым переходом нужен «удерживающий» кейфрейм —
иначе канал начнёт уползать к следующему значению за полглавы до перехода.

**Музыка.** Положить трек в `public/audio/trendsetter.mp3`, выставить в
`MUSIC`: `enabled: true`, реальные `bpm` и `offsetSec` (секунда первой доли).
После этого сцены пересобираются под бит правкой одной константы.

**Цифры и категории.** `src/data/categories.ts`: `STATES` — четыре состояния
диаграммы (каждое в сумме 100), `CHART_KEYFRAMES` — когда происходит переход.
Диаграмма и список читают одни и те же значения, поэтому расхождений быть не может.

**Бренд.** `src/theme.ts` — цвета и типографика. Точный HEX гранатового
красного меняется в `brand.red`.

**Моушн.** `src/motion.ts` — единственное место, где живут кривые. `easeOutBack`
даёт перелёт (рост сегментов, появление слов), `drift` — органическое покачивание
из трёх синусов, `kick` — импульс на границе сцены, `SPRING` — четыре пресета
пружин. Амплитуда движения камеры настраивается в `src/components/Camera.tsx`:
множители при `drift(...)` и `cutZoom`.

**Логотип.** Заменить тело `src/components/Logo.tsx` на
`<Img src={staticFile('logo/anorbank.svg')} />` — больше нигде логотип не используется.
